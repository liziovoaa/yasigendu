跟读神器 · 使用说明
================================================
一个本地网页工具：内置 2026 年 9-12 月雅思口语题库（102 个话题），
并且每个话题都配好了参考答案（P1 逐题答案 242 道 / P2 独白 63 篇 /
P3 示范答 364 道）。选题 → 看答案 → 一键填入 → 美式发音逐句跟读 →
录音对比。无需安装，双击即用。
另外配了一张「串题地图.html」，63 张 P2 卡按素材归了类，考前看那张（见【五】）。
参考答案带中文对照，一句英文一句中文，看不懂时点开看（见【六】）。


【一、怎么打开】
Windows：双击「yasigendu.html」，用 Edge 打开。
Mac：    双击「yasigendu.html」，用 Edge 打开（为什么不能用 Safari 见【二】）。

注意：这些文件必须放在同一个文件夹里，要一起拷贝：
      必需  「yasigendu.html」「题库数据.js」「答案数据.js」「中文译文.js」
      可选  「串题地图.html」考前串题用
            「语调实验.html」语调诊断用（见【八】）
            「语音诊断.html」没声音时排查用（见【十】）
            「使用说明.txt」本文件
      少拷 JS 的话，题库和答案会显示"未加载"，朗读和录音照常可用。


【二、Mac 用户：请用 Edge 打开，别用 Safari】
Safari 的音色明显偏机械，这是它的硬限制：读不到系统里下载的
高质量语音，天花板就是系统自带的低质量音色（装了增强包反而会消失）。

  右键「yasigendu.html」→ 打开方式 → Microsoft Edge

Edge 自带 250+ 个微软神经网络语音，免费、不用装语音包，
音质和 Windows 上一样自然。没装的话 https://www.microsoft.com/edge

小提示：Edge 在 Mac 上刚打开时只列出十几个音色，
先点一次「整篇播放」，它会自动载入完整列表（状态栏会提示），
再去「音色」下拉框挑名字带 (Natural) 的，如 Aria / Ava / Guy。

Windows 用户：用 Edge 打开即可，一般不用额外设置。

两边都一样：右上角徽章显示绿色「美式自然语音」就说明选对了。

手机上（iPhone / iPad）：换浏览器没用
iOS 上 Chrome、Edge、Firefox 全都是苹果 WebKit 内核，
共用同一个系统语音库 —— 换浏览器，音色一模一样。
想好听只有一条路：去系统设置里下载高清语音。

  设置 → 辅助功能 → 朗读内容 → 语音 → 英语（美国）→
  点 Ava / Samantha / Zoe / Evan 后面的云朵图标，
  下载标着「增强 / 高级」的那一版（几十到两百多 MB，建议连 Wi-Fi）。

下完关掉页面重新打开（或下拉刷新），音色下拉框里就会出现它们。
名字带 Enhanced / Premium 的就是高清版，页头徽章会变成绿色「高清语音」。

美式音色推荐：
  女声  Ava (Premium) —— 最接近雅思听力录音的语调
        Samantha (Enhanced) —— 经典、稳定，几乎每台机器都有
  男声  Evan (Premium) 或 Tom (Enhanced)

用 iPhone 版 Edge 的话：它的「大声朗读」是微软语音，但那是 App
自带的功能；网页里调朗读，用的还是苹果系统语音，跟 Safari 完全一样。
最新的 iOS 有个别版本对网页只放出低质量音色，属于苹果自身的变化，
下载的增强语音在网页里不出现也不必奇怪 —— 用手机听个大概即可，
精听跟读还是建议在电脑上用 Edge。


【三、录音功能】
录音需要麦克风权限。

  Windows：浏览器弹权限框，点「允许」。

  Mac：有两层开关，两层都要开——
    1) 系统设置 → 隐私与安全性 → 麦克风 → 勾上你用的浏览器
    2) Safari → 设置 → 网站 → 麦克风 → 对应网站选「允许」

如果双击打开网页后录音用不了（右上角提示「需用本地服务打开」）：
  Windows：双击「启动本地服务.bat」
  Mac：    双击「启动本地服务.command」（提示无法打开就右键 → 打开）
  它会自动打开 http://localhost:8777/ 的本地页面，在那儿录音就正常了。
  运行时那个黑窗口别关，用完 Ctrl+C 或关掉即可。


【四、怎么用】

第 0 步（建议）：从题库选题
  点左下角「📚 题库 102」→ 从左侧滑出题库列表
  · 顶部标签切换：大陆地区新题 / 大陆地区保留题 / 非大陆地区新题
    在大陆考的同学，看前两个 + 里面的"万年老题"就够了
  · 搜索框能搜话题名和题目内容，中英文都行
    （比如搜 "websites" / "种菜" / "decision"）
  · 点任意一题，题目就显示在左上角，抽屉自动关闭
  · 题卡上的「朗读题目」会用考官口吻读一遍，可以练听题
  · 题目多的时候，点「收起」把题卡折起来，给输入框腾地方
  · 题库来源：2026 年 9-12 月换题季（雅思哥考生回忆汇总）
    共 P1 39 个话题 + P2&3 63 张卡片
  · 列表里带绿色 ✓ 的 = 已经写好参考答案（现在 102 个话题全都有）
  · 抽屉顶部有「只看已写答案的」勾选框

第 1 步：看参考答案
  选完题，题卡下方会自动展开「参考答案」面板：
  · P1：列出每一道小问 + 对应答案，每题前面有个 ▶ 可以单独试听
  · P2：整段独白（约 180 词），下面是 P3 追问的示范答
  · 点「填入答案」→ 答案自动灌进输入框并生成跟读卡片，面板自动收起
  · 点「只填 P3」→ 只把 P3 那几段填进去，单独练
  · 不想看就点右上角「收起答案」

  注意：参考答案是给你照着改的模板，不是让你背的。
  里面的人设是「上海教数学的老师，养了一只猫」，跟你实际情况不一样，
  把细节换成你自己的（见【九】最后一条），否则 Part 3 一追问就露馅。

第 2 步：跟读
1. 答案在输入框里 → 点「生成跟读卡片」
2. 点「整篇播放」：读一句 → 停顿 → 你跟读 → 下一句
3. 想单独练一句：点「录音」念一遍 → 自动播放「原声 vs 你的」对比
   · 录完会留下波形和时长对比，比如「我的 5.1s · 原声 4.2s · +0.9s 偏慢」
   · 雅思 fluency 一大扣分点就是节奏拖沓，这个数字很直观
4. 语速默认 0.95（略慢），练熟后往 1.1~1.2 推，接近真实语速
5. 跟读停顿默认 2 秒，来不及开口就调大

双击「串题地图.html」。它把 63 张 P2 卡按"能不能共用一个素材"重新排了一遍，
不是按题库顺序——考前该看的是这张。

  7 个核心素材 → 撑起 35 张卡
    M2 教学十年（13 张）   M9 设计师小林（5）   M5 爷爷（4）
    M3 成都 · 西安（4）    M6 上海城市（3）     M7 那台相机（3）
    M4 跑友老魏（3）
  3 组框架复用 → 再省掉 7 张
    立法三张 / 建筑两张 / 手机成瘾两张
  21 张单点 → 没有可借的素材，只能一张一张准备

怎么用：
  · 蓝底 = 整段复用。同一段话，换开头和落点，就能打这一竖排的所有卡。
  · 橙底 = 框架复用。论述结构照搬，例子必须换。
  · 灰底 = 单点。每条后面跟一个记忆钩子，一句话，够撑两分钟。
  · 搜索框搜卡名、素材名、关键词都行。搜"礼物"，M9 和单点里的那条会一起出来。
  · 顶部可以只看某一类；「打印 / 存 PDF」是双栏排版，A4 两页，打出来当速查表。

点卡名会跳到跟读神器，自动定位到这道题并展开答案。
（两个文件必须在同一个文件夹，并且用同一种方式打开——都双击，或都走本地服务。）

一句提醒：串题的前提是那段话真能挪。表里每张卡右边的「改造点」，
就是这道题跟骨架不一样的那一句，一定要看。开头原封不动搬过去，Part 3 一问就露馅。


【六、中文对照（答案看不懂时用）】

参考答案面板右上角有个「中文 ✓」按钮，默认是开着的。

  开  → P2 独白按句拆开，每句英文下面跟一行灰色中文，一句对一句
        P3 每道追问、P1 每道问答下面各挂一段中文，是整段的意译
  关  → 回到原来的整段英文，界面更清爽，适合已经读顺了以后

为什么按句拆：跟读是一句一句读的，中文也得一句一句对，眼睛左右一扫就能对上。
中文是意译，不是硬翻——「That's rarer than it should be.」译成
「这样的态度其实挺难得的」，比「这比它本应的样子更罕见」好懂，也更像人话。

全部内容已配中文：P2 独白 63 篇 755 句、P3 追问 364 道、P1 问答 242 道，
合计 1361 条译文、约 4.4 万字。任何一张卡打开都有中文。

注意：多了一个文件「中文译文.js」，它和「答案数据.js」在同一个文件夹，
四个文件要放在一起，少一个中文就不显示（不影响英文跟读）。


【七、语音标注怎么看】
每句会自动标出重读、节奏和语调，照着念能明显摆脱"中式一字一顿"：

  Actually   深蓝加粗加大 = 句子重音（这个意群里最重的那个词，重读它）
  really     加粗         = 词重音（正常重读）
  to         灰色小字     = 弱读（要读得又快又轻，鼠标悬停能看到弱读音标）
  |          红色竖线     = 意群停顿（到这里换气 / 稍停）
  ‿          橙色符号     = 连读（前后两个词要连起来念）
  ↘ ↗ →      句末符号     = 降调 / 升调 / 延续调

每句下面还有一条蓝色曲线，是这句的音高走势示意。

觉得自动标得不对：直接点那个单词，就能在「重读 ⇄ 弱读」之间切换。
想让朗读节奏也跟着标注走：勾选控制条上的「按标注朗读」，
它会在意群处插入停顿，读起来更贴近标注（默认关闭，可自行试听对比）。
不想要标注：取消勾选「语音标注」即可。


【八、语调诊断（看自己念得像不像）】

跟读器里那句「音高走势示意」是照文本规则画出来的示意图，不是你自己的声音。
现在录完音，程序会分析你自己那句的真实音高，判句末到底是升还是降。

在右栏每句卡片里，录完音后波形下面多一行，长这样：

  语调 ↘ 降 对 · 该↘ · 音域 7.8 半音 · 有声 90%  [看曲线]

  前面那个 ↘      = 你实际念出来的句末方向
  「对 / 该升却降了 / 该降却升了」= 跟这句应有的语调的对比
  「该↘」        = 按句型这句应该怎么收（和上面标注区的符号一致）
  音域 X 半音    = 起伏幅度，低于 6 偏平、6–11 自然
  有声 90%       = 这句有多少比例真的发出了声音
  点「看曲线」   = 展开音高曲线，再点收起

曲线怎么读：
  · 蓝线          = 你的音高。往上爬是语调升，往下走是降
  · 线断开        = 清音（s / f / th）或换气，不是漏检
  · 浅灰柱子      = 音量。柱子太矮说明这句读虚了
  · 浅蓝底色      = 最后 0.4 秒，判升降就看这一段

判定规则（和标注区保持一致）：
  陈述句、特殊疑问句（what/why/how 开头）→ 句末该降 ↘
  一般疑问句（Yes/No 问句）                → 句末该升 ↗
  列举（A, B, and C）                      → 前面升，最后一项降

关于准确度（说明白免得你怀疑）：
  · 基频提取实测误差 0.3% 左右（拿已知语调的音频验过，升降方向全对）
  · 音域跨度会比真实值略小（截了两端极端值防噪声）
  · 句末升降的阈值是 ±1 个半音，1 个半音以内会显示「→ 平」，
    这是保守处理：宁可说"太偏平"，也不冤枉你
  · 句型判断是规则式的，英语语调有例外，只当参考

录音时程序已经关掉了降噪、回声消除、自动增益——这三项会削掉元音尾部，
把音高曲线弄断，语调就判不准了。所以录音比之前稍微"原声"一点，是正常的。


【八之一、语调实验页（单独练一整段时用）】

文件夹里还有一个「语调实验.html」，单独打开，不影响跟读神器。
它做同一件事，但能一次录一整段（含自动分句），给出的信息更多：

  音域跨度 / 说话音区 / 有声占比 / 句间停顿 / 句末走向 五个格子
  逐句表：每句的时间、句末走向、幅度、该升该降，右边「▶ 这句」单独回放
  鼠标悬停在曲线上，能看那一刻的时间、频率、半音数

用法：双击「语调实验.html」（同样建议用 Edge）→ 选一句或自己改写 →
点「开始录音」→ 念完点「停止录音」→ 自动出图（20 秒录音也只要几十毫秒）。

什么时候用它：想一次练三五句、看整段的停顿和起伏分布，或者想量一下
自己平常说话的音区在哪儿。单句精练用跟读器就够了。

如果「有声占比」很低或者图是空的：声音太小或离麦太远，靠近点重录。

【十、常见问题】
Q：点了「整篇播放」没声音？
A：按这个顺序查，90% 是第一条：
   1) 你是不是在某个软件自带的「预览窗口」里打开的？
      那种窗口（嵌套页面）几乎一定会把语音拦掉。请关掉，
      到文件夹里右键「yasigendu.html」→ 打开方式 → Microsoft Edge。
      页面右上角如果是红色「预览窗口 · 语音可能不出声」，就是这个原因。
   2) Edge 把本页静音了？看地址栏右侧有没有一个小喇叭图标（被划掉
      就是静音），点一下取消；也看下 Windows 右下角音量合成器里
      Edge 的音量是不是被拉到 0。
   3) 音色是不是带 Online / Natural 字样的？（比如 Ava Multilingual
      Online）这类是微软的在线语音，要连服务器，国内网络经常连不上，
      表现就是「点了没反应、完全没声」。
      解决：把音色换成不带 Online 的本地音色，例如
      Microsoft Zira Desktop / David Desktop / Mark Desktop，一定能出声。
      新版程序会自动帮你换过去，并在状态栏提示「已自动换成本地音色」。
   4) 上面都排除了 → 双击「语音诊断.html」，点「开始诊断」，
      它会一行行告诉你卡在哪：浏览器 / 音色数量 / 每个音色能不能出声。
      把结果发我。

Q：音色下拉框是空的？
A：系统没装英语语音。Windows：设置 → 时间和语言 → 语言 → 添加
   「英语(美国)」并安装语音包。Mac：按【二】装增强语音。

Q：读了一句就停住了？
A：点音色右边的「刷新」重新载入；或换个音色试试。

Q：录不到声音？
A：看右上角麦克风徽章。红色说明被拦了，按【三】处理。
   录音时下方有实时音量条，会动才说明麦克风在收声。

Q：每点一次「录音」都弹一次麦克风权限？
A：两个原因，新版都已经处理：
   1) 以前每次录完就把麦克风连接关掉了，下次又得重新申请。现在改成
      整页只申请一次，同一个页面里连着录多少句都不会再弹。
   2) 如果你是把 HTML 直接双击打开的（地址栏是 file://），浏览器记不住
      这份授权，关掉页面重新打开还会问一次 —— 这是浏览器的限制，绕不过。
      想只问一次，就用「启动本地服务.bat」打开（地址变成 http://localhost），
      在那里点一次允许，之后一直有效。
   补充：麦克风连接会一直留着以便复用，所以 Windows 任务栏那个麦克风指示灯
   在页面开着时会亮着，关掉页面就灭，属正常。徽章变成
   「麦克风可用 · 每次要授权」就是第 2 种情况。

Q：题库按钮显示"未加载"，或者点不出来答案？
A：「题库数据.js」「答案数据.js」「中文译文.js」要和 HTML 放在一起。
   四个文件拷到同一个文件夹即可（少了中文译文只是不显示中文，不影响跟读）。

Q：参考答案能直接背吗？
A：不建议，也背不下来。这套答案的用法是"改"，不是"背"：
   1) 先把细节换成你自己的（学校、城市、家里几口人、那只猫叫什么）
   2) 再把你不顺口的句子改简单——说不顺的 8 分句，实际只值 6 分
   3) 背下来的痕迹（语调平、词汇突然跳级）考官一眼能看出来，会压 fluency

Q：P3 的答案为什么这么短？
A：每条约 25 词（念出来 12~15 秒），是"骨架级"示范：给出
   态度 + 一个理由，够用但不铺开。P3 想上 7 分，每题要说到
   40~60 词，加一个具体例子。练习顺序建议：先照着骨架把流畅度
   练上来，再自己往每条后面加半句例子。
